# Connector

   <img src="./public/512x512.png" height="100" width="100" alt="connector-logo">
</div>

A lightweight, cross-platform desktop application for building, testing, and managing API requests. Built with Tauri, React, and Rust.

🌐 **Try it online**: [connector-ten.vercel.app](https://connector-ten.vercel.app)
💻 **Download Desktop App**: [Latest Release](https://github.com/sazzad-anwar/connector/releases/latest)

## Features

- 📁 **Collection Management**: Create, organize, and manage API collections and folders
- 🔄 **API Testing**: Test REST APIs with support for various HTTP methods
- 🔌 **Request Configuration**:
  - Query parameters
  - Path variables
  - Headers
  - Request body (JSON, Form Data)
- 👁️ **Response Visualization**:
  - JSON preview
  - Image preview
  - Video preview
  - HTML preview
- 🔄 **Environment Variables**: Support for dynamic variables and environment management
- 📥 **Import/Export**: Import and export collections
- 🌓 **Dark/Light Mode**: Built-in theme support
- ⚡ **Lightweight**: Efficient performance with minimal resource usage

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Backend**: Rust, Tauri
- **State Management**: Zustand
- **UI Components**: Radix UI, shadcn/ui
- **Editor**: Monaco Editor
